# 関連語の想起課題ジェネレータ

**対象**：小学4年生〜高校3年生の、知的発達に遅れのある子ども・ASD・ADHD・LD の子ども。かなの読み書きができることを前提とする
（2026-10-23 確認）。課題の難しさは生活年齢ではなく発達年齢で選ぶ。
なかでも、語彙が不足している子、意味ネットワークがうまく形成できていない子、ことばが経験と結びついていない（記号接地していない）子、
場面に合う語を選べていない子を対象とする。精神発達が10歳前後に達している子には実施しない。

特別支援・療育向けの「関連語の想起課題」プリント（A4縦・印刷用PDF）を、内容を
差し替えて何枚でもバッチ生成するローカルCLIツールです。Webサービスではなく、
手元で印刷用PDFを量産して販売する用途を想定しています。**完全ローカル動作・
ネットワーク不使用**。

- 1商品 = **A4縦1枚 = 1テンプレート × 問題2問**（問題1・問題2）。1枚に複数
  テンプレートは混在しません。
- ページのタイトルは大問帯の「ローマ数字＋子ども向け表示名」のみ
  （例「Ⅲ　ことばのペアをつくろう」）。「関連語の想起課題」や臨床名・通し番号は
  PDFに出しません（臨床名は手元管理用 manifest にのみ記録）。
- モノクロ印刷で破綻しない設計（色に依存しません）。
- 漢字にはすべてふりがなを付けます（`data/furigana.yaml` の読みを使用。未登録の漢字があると
  生成時にエラーで停止）。
- 語は漢字＋ルビで表示します（2026-10-26）。データはひらがなで書き、`data/kanji.yaml`（ひらがなの語 → 漢字《よみ》）で
  表示の形を決めます。常用漢字で、ふだん漢字で書く語だけを漢字にし、意味が文脈で分かれる語・常用漢字にない字の語・
  ふつう かなで書く語は かなのままです。マスに1音ずつ書く字（Ⅶ・ⅩⅢ・ⅩⅦ）は かなのまま書きます。
  音の数・音の位置などは、データのひらがなで数えます。
- 語・関係データは**コード直書きせず** `data/*.yaml` に外出し。専門職が後から
  自由に追加・修正できます。
- `--seed` で乱数固定（再現可能）。同一セット内で同じ問題（中心語・カテゴリー名など）が
  重複しません（表記ゆれも同じものとして判定）。
- 使用語・正解を記録した `*_manifest.json` を出力します。

どの課題も、ねらいは語の意味の力で、かなの読み書きではありません（評価レポート §13）。
読み書きの負荷が大きい子には、支援者がその場で判断して、口で答えた語を書き取ったり、語を読み上げたりしてください
（プリントには書いていません）。


## はじめる順（発達の道筋から見た目安）

フォルダの番号は課題の通し番号で、取り組む順ではありません。文献 Wiki（`wiki/`）の発達の道筋から、
前提となる力が少ない順に並べると次のようになります。レベル番号は課題の中での難しさで、
課題をまたいで比べられません（例：Ⅶ Lv1 は Ⅵ Lv2 より易しいとは限らない）。

| 順 | 課題 | 必要な力（下位スキル） | 主な根拠（Wiki のノート） |
|---:|---|---|---|
| 1 | Ⅸ 仲間えらび・Ⅹ ベン図えらび Lv1（大人が読み上げれば読み書き不要） | カテゴリーの知識（Ⅹ は2つの条件を同時に見る力も） | SV-09、VO-10 |
| 2 | Ⅱ 意味ネットワーク照合 | 語彙・主題的な関係の知識、単語を読む | SV-08、RW-01 |
| 3 | Ⅲ ペア対応づけ Lv1〜2 | 関係の知識、単語を読む | — |
| 4 | Ⅰ 連想チェーン | 動詞の語彙、ダミーを退ける抑制 | SV-11、SV-09 |
| 5 | Ⅵ カテゴリー流暢性（まず5行版） | カテゴリーを手がかりに語を探す、かなを書く | SV-12、RW-01 |
| 6 | Ⅳ 放射状連想 Lv1〜2・Ⅴ つづき歌 | 手がかりの少ない自由想起、かなを書く。Ⅴ は Lv1（関係のあることば）→ Lv2（なかま）→ Lv3（なかま・いっしょを交互） | SV-08、SV-09 |
| 7 | Ⅶ 語頭音とモーラ数 | 語頭音の抽出、モーラ分解、音で語を探す、特殊音節を書く | PA-01、PA-02、PA-05、RW-03 |
| 8 | Ⅹ Lv2 → Ⅷ 属性交差 | 2つの条件の同時処理、「だけ」「どちらでもない」の理解。Ⅷ は自分で例を考えて書くので、選ぶ Ⅹ より後 | SV-17、SV-18、SV-22〜SV-24 |
| 9 | Ⅲ Lv3・Ⅳ Lv3 | 同義語・抽象語（学齢期後半の内容） | SV-04、SV-16 |

この順は複数の文献を組み合わせた推定で、子どもへの試行では確かめていません。

**ことばが経験と結びついていない（記号接地していない）子には**、このプリントより先に、実物にさわる・実際に動作をする・
その場で体験する指導を行ってください。紙の課題は文字の語どうしで完結するので、語と語の結びつきだけで正答できてしまい、
接地をつくることも、接地しているかを確かめることもできません（Wiki WL-10・WL-13）。そのため接地の段はプリントにしていません。

**音韻意識のプリント（Ⅶ・Ⅺ〜ⅩⅣ）を使うときの注意**（Wiki PA-01〜PA-08、PW-11・PW-12）
- かなが読める子は、文字を数えれば音の数が分かってしまいます（清音・濁音の語では、文字の数と音の数が同じ）。
  必ず声に出して言いながら、1音ごとに手をたたく・○をぬる・シールをはるようにしてください。
  かなは読めるのに音の意識が育っていない子（大六, 1995）では、ここが練習の中心になります。
- **文字を見ずに答える使い方**：Ⅻ・ⅩⅢ・ⅩⅦ は、文字の見た目（最初・最後の字、字を右から読む）でも解けてしまいます。
  音の操作そのものを練習するときは、大人が問題の語と指示を読み上げ、子どもは紙の語を見ずに（手でかくして）答え、
  答えだけをマスに書く（または口で言う）形にしてください。ⅩⅦ は言語聴覚士の公開教材「音韻操作（口頭命令に従う）」
  （縁の下の言語聴覚士）と同じく、口頭で指示を出す使い方ができます。
- 濁音・半濁音（が・ぱ）も1つの音です。Ⅺ Lv2 で確かめ、Ⅻ Lv2〜3 では清音と濁音・半濁音の聞き分け（こ／ご、ぱ／ば）を入れています。
- はじめる順の目安：Ⅺ（音の数：分解）→ Ⅻ Lv1（はじめの音）→ Ⅻ Lv2（おしまいの音）→ ⅩⅣ（音から言葉を集める：始まる音 → 終わる音）→ Ⅶ（音とマスの数から語を探す）
  → ⅩⅢ（ぎゃくから言う → 音をとる）→ ⅩⅦ（指示どおりに音を変えて、別のことばにする）。逆唱は2音5歳後半・3音6歳前半・4音7歳前半、削除は2〜3音6歳前半が通過の目安です（原, 2001・2012）。

**文のプリント（ⅩⅤ・ⅩⅥ）を使うときの目安**（Wiki GR-31〜GR-37、ND-20〜ND-24）
- 順番：ⅩⅤ Lv1（2語・助詞なし）→ ⅩⅤ Lv2（3語・助詞なし）→ ⅩⅥ Lv1（助詞1つ）→ ⅩⅥ Lv2（が・を、意味で決まる文）
  → ⅩⅤ Lv3（どこで・なにでを加える）→ ⅩⅥ Lv3（可逆文・語順の入れかえ）。
  定型児では2語連鎖が2歳前半、3語連鎖が3歳後半、助詞「が」「を」による理解は5歳後半です（〈S-S法〉）。
  知的障害のある中高生では、非可逆・基本語順の文は正答80%以上、可逆・非基本語順の文は40%未満でした（村尾, 2022）。
- 前提：使う名詞と動詞を、読めて意味が分かることを確かめてください。語結合・助詞は表出語彙の量（特に動詞）に支えられます。
- 枠の形は Shape Coding（Ebbels, 2007：RCT で大きな効果）をモノクロにしたものです。形と疑問語で役割を示し、なくても文になる項
  （どこで・なにで）は破線です。形とラベルだけで効果が保たれるかは検証されていません。
- 「が」「を」が書けていても、語順で当てていることがあります。ⅩⅥ Lv3 の可逆文・語順を入れかえた文で確かめてください。
  ⅩⅤ では、文の長さと助詞の正しさを分けて見てください（ダウン症では助詞が特に遅れるとの報告：ND-20）。

**ベン図（Ⅷ・Ⅹ）を使うときの目安**（Wiki SV-17〜SV-25）
- 2つの条件で分ける力は、課題の形で成功年齢が大きく変わります。条件を言われて合うものを選ぶ形（Ⅹ）は4〜5歳でも成功することがあり、
  自分で規則や例を見つける形（Ⅷ）は6〜8歳ごろまで難しいとされます（土居, 1977；Podjarny et al., 2017, 2022；Nguyen & Murphy, 2003）。
- 「のりもの？ そらをとぶ？」のように、条件を口に出しながら置かせると、6歳児の成績が上がったと報告されています（土居, 1977）。
- 「〜だけ」は、文で読ませるより図のラベルで示すほうが安全です。幼児の「だけ」の理解は、付く位置と助詞で正答率が大きく変わります（Matsuoka, 2007）。
  そのため Ⅷ・Ⅹ では、円の中に「ひだりだけ・りょうほう・みぎだけ」を薄く書いています。
- 「どちらでもない」（円の外）を子どもで直接調べた研究は見つかっていません。Ⅹ では3つの場所（Lv1）に慣れてから加えます（Lv2）。
- 自閉スペクトラム症の子どもは、1つの条件だけで分けやすい傾向が報告されています（Edwards et al., 2012 など）。
  全部を片方の円に入れていないか、「りょうほう」を使っているかを見てください。

**誤り方を見る視点**（正答の数より、どう間違えたかがつまずきの手がかりになります。Wiki ND-01・ND-05〜ND-09、SV-30）
- **近いカテゴリーとの取り違え**（Ⅵ・Ⅸ Lv2）：「さかな」に いか・くじら、「むし」に くも など。知的障害のある生徒で多い誤りです。
  意味ネットワークの境界がまだあいまいなことを示します。Ⅸ Lv2 で同じ取り違えが出るかを確かめてください。
- **似た種類のダミーに引かれる**（Ⅱ Lv3・Ⅰ Lv3）：場面ではなく、種類の似ている語を選ぶ。分類で結びつける傾向
  （ASD で報告）か、抑制の弱さ（ADHD）が考えられます。
- **片方の条件だけで分ける**（Ⅷ・Ⅹ）：「りょうほう」が空のまま、どちらかの円に全部入れる。
- **切り替えない・同じ下位カテゴリーで続ける**（Ⅴ Lv3・Ⅵ）：つなぎ方を切り替えられない、「どうぶつ」で
  ペットだけを続ける、など。ASD・ADHD で報告されています。
- **選べるが書けない・説明できない**（Ⅸ↔Ⅵ、Ⅹ↔Ⅷ）：選ぶ版はできるのに書く版ができないときは、知識はあっても
  思い出せていない（検索のつまずき）可能性があります。読み書き障害・DLD では、意味のつながりより検索の遅さが
  目立つとされます。
- **戻り先の目安**：書く課題でつまずいたら、同じ内容の選ぶ版（Ⅵ→Ⅸ、Ⅷ→Ⅹ）へ。分類学的な関係（なかま）で
  つまずいたら、主題的な関係（Ⅱ・Ⅰ・Ⅴ Lv1）へ。
かなの読み書きが育ちきっていない子では、書く課題（5〜8）の前に、書かない版（1）や大人が書き取る形を使ってください。


## セットアップ

```
pip install -r requirements.txt
```

日本語フォント（Noto Sans JP の静的TTF）は `fonts/` に同梱済みです。追加の
ダウンロードは不要です。


## 使い方

### 印刷するとき（ふだんはここだけ）

`プリント/` を開きます。課題は番号順、レベルは Lv1〜Lv3 のフォルダに分かれています。

```
プリント/
├── 01_連想チェーン/
│   ├── Lv1/  01_連想チェーン_Lv1_問題.pdf ／ 01_連想チェーン_Lv1_解答.pdf
│   ├── Lv2/
│   └── Lv3/
├── 02_意味ネットワーク照合/
├── 03_ペア対応づけ/
├── 04_放射状連想/
├── 05_つづき歌/
├── 06_カテゴリー流暢性/
├── 07_語頭音とモーラ数/
├── 08_属性交差ベン図/
├── 09_仲間えらび/      … Ⅵ の書かない版
├── 10_ベン図えらび/    … Ⅷ の書かない版
├── 11_おとのかず/ ・12_おとさがし/ ・13_おとけしとぎゃくよみ/ ・14_おとからことばあつめ/ … 音韻意識
├── 15_ぶんをつくろう/ ・16_じょしをいれよう/ … 二語文・三語文、格助詞
├── 17_ことばへんしん/ … 音韻操作（指示どおりに音を変えて別のことばにする）
└── _生成記録/   … 各PDFに使った語の記録（ふだんは見なくてよい）
```

- 各レベルの PDF には、そのレベルの問題がすべて1回ずつ入っています（1枚2問）。
- 解答は、正解が1つに決まる Ⅰ・Ⅱ・Ⅲ・Ⅶ・Ⅸ・Ⅹ・Ⅺ・Ⅻ・ⅩⅢ・ⅩⅤ（こたえの例）・ⅩⅥ・ⅩⅦ にあります（`_解答.pdf`）。
- Ⅵ には、記入行が5行の版（`_問題_5行.pdf`）もあります。書くのに時間がかかる子や年少の子に。
- 問題が1問しかないレベルは、1枚に満たないので作られません（いまは該当なし）。

### 語を直したあと、プリントを作り直す

`data/templates/*.yaml` を直したら、次の1行で `プリント/` を丸ごと作り直します（古い出力は消えます）。

```
python generate.py --catalog
```

並び順・フォルダ名は `products.yaml` の `catalog` で決まります。

### 1種類だけ試しに作る

```
python generate.py --type IV --level 2 --count 3 --seed 1 --with-answers   # → プリント/_試し/
```

## CLIオプション

| オプション | 説明 |
|---|---|
| `--type` | `I`〜`VIII` から1つ。1回の実行で同一テンプレートのみ生成。 |
| `--level` | 難易度 `1`〜`3`（省略時は全レベルから出題）。 |
| `--count` | 生成する枚数（＝商品数）。1枚ごとに問題1・問題2の内容を変える。 |
| `--seed` | 乱数シード。同じ値なら問題・配置・PDFをバイト単位で再現。 |
| `--out` | 出力ディレクトリ（省略時：`--catalog` は `プリント/`、それ以外は `プリント/_試し/`）。 |
| `--with-answers` | 正解が一意な Ⅰ/Ⅱ/Ⅲ/Ⅶ の解答PDFも出力。 |
| `--name` | 出力ファイル名の幹（省略時 `type_<種別>`）。 |
| `--catalog` | `products.yaml` の `catalog` に従い、全課題・全レベルを `プリント/` に作り直す。 |
| `--base-dir` | `data/` と `fonts/` の基準ディレクトリ。 |

> `--level` 指定時、そのレベルのitemが枚数に足りない場合は自動的に全レベルへ
> 広げて出題します（標準出力に注記）。データ自体が不足する場合はエラーで停止
> するので、`data/templates/*.yaml` にitemを追加してください。


## 難易度（--level 1〜3）

- Ⅰ・Ⅱ: ダミー語の近接度（遠い=易 / 近い=難）。
- Ⅲ: 関係の種類の発達の順。Lv1 は機能・部分と全体・場面の関係と反対のことば（ようす）、Lv2 は知識の要る関係
  （すみか・こども・材料・職業の道具）と反対のことば（うごき）、Lv3 は似た意味のことば（Wiki SV-29・SV-32）。
- Ⅳ: 中心語との関係の種類。Lv1 は場面・行事・身近なもの（主題的）、Lv2 は「赤いもの」のような属性、Lv3 は抽象語・感情語。
- Ⅵ: カテゴリーの抽象度（具体物=易 / 抽象=難）。
- Ⅴ: つなぎ方の種類で段階化。Lv1 は「かんけいのあることば」（つなぎ方は自由）、Lv2 は「おなじなかま」、Lv3 は「おなじなかま」と「いっしょにあるもの」を交互に。
  矢印の横につなぎ方を書く（item の `relation:`）。
- Ⅸ: Lv1 は仲間でない語が遠い（別の領域の物）、Lv2 は近い（となりのカテゴリー）。
- Ⅹ: Lv1 は3つの場所（左だけ・両方・右だけ）、Lv2 は「どちらでもない」を加えた4つの場所。
- Ⅶ: 特殊音節で段階化。Lv1 は直音の語だけ（マス2〜4音）。Lv2 は撥音・長音で、1行に「ん」または長音の字を
  あらかじめ書いておく（item の `fixed:`）。Lv3 は拗音・促音で、語頭音を拗音（例「しゃ」）にするか、1行に「っ」を
  書いておく。答えが拗長音（きゅう・しょう など）になる行には、のばす音の「う」も書いておく。ページ下部の【マスの書き方】はページ内の最も高いレベルに合わせて変わる。解答例は語頭音・音数・
  書いておく字・レベルの条件（Lv1 は特殊音節なし、Lv2 は拗音・促音なし）を生成時に自動検査。
  あわせて語頭音の語の多さも見る。Lv1 は、その音から始まる語が多い音（教育基本語彙の低学年配当で110語以上）にする
  （頭音での想起語数は、その音の語の多さに強く左右される：Wiki SV-27）。

各itemの `level:` で水準をタグ付けしています。


## データの編集（data/）

- `data/config.yaml` … フォントパス、ヘッダー表示名など全体設定。
- `data/templates/*.yaml` … テンプレート別の語・関係データ（itemの集合）。
- `data/furigana.yaml` … ふりがな辞書。キーはPDFに描く文字列、値は `漢字《よみ》` 形式。
  漢字を含む語を追加・変更したら、ここにも読みを追加してください。

各item先頭の `id` は記録用です（省略時は自動採番）。重複の判定は `id` ではなく問題の
中身（Ⅳ中心語・Ⅵカテゴリー名など）で行います。漢字/かなの書き分け（文房具／ぶんぼうぐ）
のように自動で同一と判定できないものは、両方の item に同じ `key:` を書くと重複として
検出されます。スキーマの要点（各ファイル冒頭のコメントにも記載）:

- **Ⅰ** `chain: [start, 列2, 列3, 列4, goal]` ＋ 各列ダミー `distractors.col2/col3/col4`
- **Ⅱ** `center` ／ `related[5]` ／ `distractors[5]`
- **Ⅲ** `relation` ／ `pairs[[左,右]×5]` ／ `extra`（右に足す、どれとも結ばない語）
- **Ⅳ** `center` ／ `hint`
- **Ⅴ** `start` ／ `example` ／ `relation`（かんけい／なかま／こうたい）／ `slots`
- **Ⅵ** `category` ／ `example` ／ `lines`（`products.yaml` の variants で5行版も作る）
- **Ⅶ** `initial` ／ `answers{2,3,4,5: [語例]}`（解答面用）／ `moras`（マスの音数。省略時 `[2, 3, 4, 5]`、Lv1 は `[2, 3, 4]`）／ `fixed`（あらかじめ書いておく字 `{音数: {位置: 字}}`）
- **Ⅷ** `left_attr` ／ `right_attr` ／ `intersection`
- **Ⅸ** `category` ／ `members[6]`（仲間）／ `others[6]`（仲間でない語）
- **Ⅹ** `left_attr` ／ `right_attr` ／ `left[2]` ／ `both[2]` ／ `right[2]` ／ `none[2]`（Lv2 のみ）

`--count` 枚（＝`2×count` 問）に対し、使用するレベルの（重複を除いた）item数が
これを上回るようデータを用意すると、そのレベルだけで生成できます。


## 品質保証

生成時に自動チェックします。

- **正解の妥当性**: Ⅰ・Ⅱ・Ⅲは正解語とダミー語の文字列の衝突・重複を検査します
  （不備があればエラーで停止）。**意味の上で別の経路が成り立たないか（例: ダミー語を
  通っても start→goal がつながる）は自動では検査できない**ので、item を追加・修正したら
  人が確認してください。
- **枠はみ出し**: 楕円・円・マス内の文字幅を測り、収まらなければ自動縮小。
  最小サイズでも収まらない場合は manifest の `warnings` に記録。
- **重複なし**: データ内に同じ中身の問題があるとエラーで停止します（レベルをまたぐ
  重複も対象）。同一セット／パック内で同じ問題は出題されません。判定キーは
  Ⅰ正解列・Ⅱ/Ⅳ中心語・Ⅲ関係名・Ⅴ開始語・Ⅵカテゴリー名・Ⅶ語頭音・Ⅷ左右の属性の組で、
  カタカナ/ひらがな・全角/半角の違いは同じものとみなします。


## 再現性

`--seed` を固定すると、出題・配置（線結びのシャッフルやダミーの並び）まで含めて
同一結果になります。問題PDFと解答PDFは同じ配置で対応します。
