# 関連語の想起課題ジェネレータ

特別支援・療育向けの「関連語の想起課題」プリント（A4縦・印刷用PDF）を、内容を
差し替えて何枚でもバッチ生成するローカルCLIツールです。Webサービスではなく、
手元で印刷用PDFを量産して販売する用途を想定しています。**完全ローカル動作・
ネットワーク不使用**。

- 1商品 = **A4縦1枚 = 1テンプレート × 問題2問**（問題1・問題2）。1枚に複数
  テンプレートは混在しません。
- ページのタイトルは大問帯の「ローマ数字＋子ども向け表示名」のみ
  （例「Ⅲ　ことばのペアをつくろう」）。「関連語の想起課題」や臨床名・通し番号は
  PDFに出しません（臨床名は手元管理用 manifest にのみ記録）。
- モノクロ印刷で破綻しない設計（色に依存しません）。
- 漢字にはすべてふりがなを付けます（`data/furigana.yaml` の読みを使用。未登録の漢字があると
  生成時にエラーで停止）。
- 語・関係データは**コード直書きせず** `data/*.yaml` に外出し。専門職が後から
  自由に追加・修正できます。
- `--seed` で乱数固定（再現可能）。同一セット内で同じ問題（中心語・カテゴリー名など）が
  重複しません（表記ゆれも同じものとして判定）。
- 使用語・正解を記録した `*_manifest.json` を出力します。


## テンプレート一覧（8種）

| 種別 | 名称 | 形式 | 解答面 |
|---|---|---|---|
| Ⅰ | 連想チェーン | 線つなぎ（スタート→3列→ゴール） | あり |
| Ⅱ | 意味ネットワーク照合 | 中心語と関連語を線結び | あり |
| Ⅲ | ペア対応づけ | 左5語・右6語（1語あまる）のマッチング | あり |
| Ⅳ | 放射状連想 | マインドマップ（中心＋8丸、ヒント1個） | なし |
| Ⅴ | つづき歌 | 語連鎖（開始語＋空欄を縦に） | なし |
| Ⅵ | カテゴリー流暢性 | 仲間集め（例語＋記入罫線） | なし |
| Ⅶ | 語頭音＋モーラ数 | マス目（2/3/4/5音、先頭に語頭音） | あり |
| Ⅷ | 属性交差 | ベン図（左だけ／右だけ／両方） | なし |

解答面（`--with-answers`）は、正解が一意に定まる **Ⅰ・Ⅱ・Ⅲ・Ⅶ** のみ別PDFで
出力します。自由記述の Ⅳ・Ⅴ・Ⅵ・Ⅷ は記入欄のみで解答面を作りません。


## セットアップ

```
pip install -r requirements.txt
```

日本語フォント（Noto Sans JP の静的TTF）は `fonts/` に同梱済みです。追加の
ダウンロードは不要です。


## 使い方

### 印刷するとき（ふだんはここだけ）

`プリント/` を開きます。課題は番号順、レベルは Lv1〜Lv3 のフォルダに分かれています。

```
プリント/
├── 01_連想チェーン/
│   ├── Lv1/  01_連想チェーン_Lv1_問題.pdf ／ 01_連想チェーン_Lv1_解答.pdf
│   ├── Lv2/
│   └── Lv3/
├── 02_意味ネットワーク照合/
├── 03_ペア対応づけ/
├── 04_放射状連想/
├── 05_つづき歌/
├── 06_カテゴリー流暢性/
├── 07_語頭音とモーラ数/
├── 08_属性交差ベン図/
└── _生成記録/   … 各PDFに使った語の記録（ふだんは見なくてよい）
```

- 各レベルの PDF には、そのレベルの問題がすべて1回ずつ入っています（1枚2問）。
- 解答は、正解が1つに決まる Ⅰ・Ⅱ・Ⅲ・Ⅶ だけにあります（`_解答.pdf`）。
- 問題が1問しかないレベル（Ⅲ・Ⅷ の Lv3）は、1枚に満たないので作られません。

### 語を直したあと、プリントを作り直す

`data/templates/*.yaml` を直したら、次の1行で `プリント/` を丸ごと作り直します（古い出力は消えます）。

```
python generate.py --catalog
```

並び順・フォルダ名は `products.yaml` の `catalog` で決まります。

### 1種類だけ試しに作る

```
python generate.py --type IV --level 2 --count 3 --seed 1 --with-answers   # → プリント/_試し/
```

## CLIオプション

| オプション | 説明 |
|---|---|
| `--type` | `I`〜`VIII` から1つ。1回の実行で同一テンプレートのみ生成。 |
| `--level` | 難易度 `1`〜`3`（省略時は全レベルから出題）。 |
| `--count` | 生成する枚数（＝商品数）。1枚ごとに問題1・問題2の内容を変える。 |
| `--seed` | 乱数シード。同じ値なら問題・配置・PDFをバイト単位で再現。 |
| `--out` | 出力ディレクトリ（省略時：`--catalog` は `プリント/`、それ以外は `プリント/_試し/`）。 |
| `--with-answers` | 正解が一意な Ⅰ/Ⅱ/Ⅲ/Ⅶ の解答PDFも出力。 |
| `--name` | 出力ファイル名の幹（省略時 `type_<種別>`）。 |
| `--catalog` | `products.yaml` の `catalog` に従い、全課題・全レベルを `プリント/` に作り直す。 |
| `--base-dir` | `data/` と `fonts/` の基準ディレクトリ。 |

> `--level` 指定時、そのレベルのitemが枚数に足りない場合は自動的に全レベルへ
> 広げて出題します（標準出力に注記）。データ自体が不足する場合はエラーで停止
> するので、`data/templates/*.yaml` にitemを追加してください。


## 難易度（--level 1〜3）

- 閉じた課題（Ⅰ・Ⅱ・Ⅲ）: ダミー語の近接度（遠い=易 / 近い=難）。
- 自由記述（Ⅳ・Ⅴ・Ⅵ）: 中心語・カテゴリーの抽象度（具体物=易 / 抽象=難）。
- Ⅶ: 特殊音節で段階化。Lv1 は直音の語だけ（マス2〜4音）。Lv2 は撥音・長音で、1行に「ん」または長音の字を
  あらかじめ書いておく（item の `fixed:`）。Lv3 は拗音・促音で、語頭音を拗音（例「しゃ」）にするか、1行に「っ」を
  書いておく。ページ下部の【マスの書き方】はページ内の最も高いレベルに合わせて変わる。解答例は語頭音・音数・
  書いておく字・レベルの条件（Lv1 は特殊音節なし、Lv2 は拗音・促音なし）を生成時に自動検査。

各itemの `level:` で水準をタグ付けしています。


## データの編集（data/）

- `data/config.yaml` … フォントパス、ヘッダー表示名など全体設定。
- `data/templates/*.yaml` … テンプレート別の語・関係データ（itemの集合）。
- `data/furigana.yaml` … ふりがな辞書。キーはPDFに描く文字列、値は `漢字《よみ》` 形式。
  漢字を含む語を追加・変更したら、ここにも読みを追加してください。

各item先頭の `id` は記録用です（省略時は自動採番）。重複の判定は `id` ではなく問題の
中身（Ⅳ中心語・Ⅵカテゴリー名など）で行います。漢字/かなの書き分け（文房具／ぶんぼうぐ）
のように自動で同一と判定できないものは、両方の item に同じ `key:` を書くと重複として
検出されます。スキーマの要点（各ファイル冒頭のコメントにも記載）:

- **Ⅰ** `chain: [start, 列2, 列3, 列4, goal]` ＋ 各列ダミー `distractors.col2/col3/col4`
- **Ⅱ** `center` ／ `related[5]` ／ `distractors[5]`
- **Ⅲ** `relation` ／ `pairs[[左,右]×5]` ／ `extra`（右に足す、どれとも結ばない語）
- **Ⅳ** `center` ／ `hint`
- **Ⅴ** `start` ／ `slots`
- **Ⅵ** `category` ／ `example` ／ `lines`
- **Ⅶ** `initial` ／ `answers{2,3,4,5: [語例]}`（解答面用）／ `moras`（マスの音数。省略時 `[2, 3, 4, 5]`、Lv1 は `[2, 3, 4]`）／ `fixed`（あらかじめ書いておく字 `{音数: {位置: 字}}`）
- **Ⅷ** `left_attr` ／ `right_attr` ／ `intersection`

`--count` 枚（＝`2×count` 問）に対し、使用するレベルの（重複を除いた）item数が
これを上回るようデータを用意すると、そのレベルだけで生成できます。


## 品質保証

生成時に自動チェックします。

- **正解の妥当性**: Ⅰ・Ⅱ・Ⅲは正解語とダミー語の文字列の衝突・重複を検査します
  （不備があればエラーで停止）。**意味の上で別の経路が成り立たないか（例: ダミー語を
  通っても start→goal がつながる）は自動では検査できない**ので、item を追加・修正したら
  人が確認してください。
- **枠はみ出し**: 楕円・円・マス内の文字幅を測り、収まらなければ自動縮小。
  最小サイズでも収まらない場合は manifest の `warnings` に記録。
- **重複なし**: データ内に同じ中身の問題があるとエラーで停止します（レベルをまたぐ
  重複も対象）。同一セット／パック内で同じ問題は出題されません。判定キーは
  Ⅰ正解列・Ⅱ/Ⅳ中心語・Ⅲ関係名・Ⅴ開始語・Ⅵカテゴリー名・Ⅶ語頭音・Ⅷ左右の属性の組で、
  カタカナ/ひらがな・全角/半角の違いは同じものとみなします。


## 再現性

`--seed` を固定すると、出題・配置（線結びのシャッフルやダミーの並び）まで含めて
同一結果になります。問題PDFと解答PDFは同じ配置で対応します。


## プロジェクト構成

```
プリント/                印刷用PDF（generate.py --catalog で作り直す）
_旧ファイル/             整理前の出力と、最初の参考資料（削除せず退避）
generate.py              CLIエントリポイント
gen/
  fonts.py               フォント登録（Noto Sans JP埋め込み）
  layout.py              ページ枠・ヘッダー・帯・描画プリミティブ・ふりがな
  data.py                YAML読込・レベル選択・重複なしサンプリング
  qa.py                  データ妥当性チェック
  render.py              セット生成（問題/解答PDF・生成記録）
  templates/t1..t8       8テンプレートの描画＋解答面
data/
  config.yaml            全体設定
  furigana.yaml          ふりがな辞書
  templates/*.yaml       語・関係データ（編集対象）
fonts/                   Noto Sans JP 静的TTF ＋ OFL.txt
products.yaml            プリントの構成（課題の並び順・フォルダ名）
requirements.txt
```
