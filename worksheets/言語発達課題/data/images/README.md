# ⅩⅧ「絵を見て文を作ろう」の絵

ここに絵の画像（PNG・JPG）を置きます。ファイル名は `data/templates/XVIII_picture_sentence.yaml` の `image:` に合わせます
（例：`e1a.png`）。何を描いた絵にするかは、同じファイルの `scene:` に書いてあります。

- 絵を置いたあと、`python generate.py --catalog` で作り直すと、絵の枠に絵が入ります（縦横の比は保ったまま枠に収めます）。
- 絵がまだない問題は、枠だけを印刷します。絵カードを貼るか、その場で描いて使えます。
- 人や動物は1つ、動作がはっきり分かる絵にします。余計な物が描いてあると、文が1つに決まりにくくなります。
- 著作権のある絵（市販の絵カード、他の団体の教材の絵など）は、公開するリポジトリに置かないでください。
  作ったプリント（`プリント/`）にも絵が入ります。
