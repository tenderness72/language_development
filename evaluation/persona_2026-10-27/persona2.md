## 4. 使いたいプリント上位3つ
1. **ⅩⅢ おとけし・ぎゃくよみ（Lv1〜3）**：原の通過年齢（PA-06）にそい、評価で使う有意味語の削除・逆唱と同じ形なので、評価の結果をそのまま指導に移せる。こたえが実在の語なので、子どもが自分で確かめられる。
2. **ⅩⅤ 文を作ろう（3つの版）**：同じレベルで言葉箱あり → なし → 助詞を書く、と変えられ、構造と喚語のどちらでつまずくかを分けて見られる（ND-24）。任意の項を破線にしているのも Shape Coding の原則に合う（GR-36）。
3. **Ⅺ おとのかず（Lv3）**：音節で数える子は っ・ん・ー を落とし（PA-05）、文字で数える子は拗音を多く数える。2つの誤りが出るので評価に使える。ただし §5-3 の修正が前提。
（次点：ⅩⅥ Lv3 の可逆文・語順の入れかえは、村尾（2022）の弱点にそのまま当たる良い課題）

## 5. 問題点（重い順）

**1. ⅩⅥ：助詞の位置が決まっていて、選び分けなくても解ける（XVI_particles.yaml）**
- Lv1 は4問すべてで が・を・が・を と交互に並び、PDF でもこの順で印刷される。Lv2 は全16文が「が…を」、Lv4 は p4a が全文「が・に」、p4b が全文「が・に・を」。
- 位置の規則だけで全問正答でき、子どもが偏りやすい「文頭のが」の方略（Hakuta, 1982：GR-34）を強める。Lv4 は「選ぶ助詞が3つ」を難しさの根拠にしているが、実際には選ぶ場面がない。
- 直し方：
  - Lv1 は順と比率（3:1 など）を乱数にする。
  - Lv2 は主語だけ・目的語だけの文を混ぜる。
  - Lv4 は同じ名詞で助詞だけが違う組（いす（に）すわる／いす（を）はこぶ、でんしゃ（に）のる／でんしゃ（を）まつ）と、「みず（を）はな（に）やる」の語順を入れる。
  - qa.py に「同じ問で助詞の並びがすべて同じなら警告」を足す。

**2. 特殊拍を音ではなく表記で決めている（XIII m4b、二重母音）**
- 道路は [doːro] で、「う」は お段長音の表記にすぎず、/u/ は聞こえない。「どうろ から う をとる」は表記の知識を問う課題になる（くうき・ゆうき は う段長音なので問題ない）。
- すいか（Ⅺ c1d、ⅩⅢ m2a）、たいこ（m3a、ⅩⅦ t2a）、かいだん（m3b）は二重母音の第二要素を含む（PA-03）。
- 音韻と表記が混ざると、誤答の原因を見分けられない。
- 直し方：
  - どうろ を ふうせん→ふせん、すうじ→すじ に替え、指示を「のばす音をとる」にする。
  - 二重母音の語は Lv4 に移すか、README に注記する。

**3. Ⅺ の段階と、文字で数えても解けること（XI_mora_count.yaml）**
- c1d かたつむり は5音で、Lv1 の条件をこえる（qa.py は音の数の範囲を検査していない）。
- Lv3 は撥音・長音・促音・拗音を1段にまとめている。文字の数と音の数が違うのは拗音を含む語だけで、っ・ん・ー の語は文字を数えても正答できる。
- 直し方：
  - Lv3 を ん・ー、Lv4 を っ・拗音 に分け、各問に拗音の語を1つ以上入れる。
  - README の誤り方の視点に「っ・ん・ー で少なく数える＝音節単位、拗音で多く数える＝文字を数えている」を足す。

**4. ⅩⅥ Lv3：状況の説明のほうが目標の文より難しい（p3a〜p3d の context）**
- 説明は「呼んでいるのは先生。呼ばれているのは友達。」のように、分裂文と受け身でできている。鈴木（2007）の先行文脈は単純な文だった（GR-34）。受け身の理解が能動文より遅いことは一般的な知見だが、Wiki では確かめていない。
- p3a の「お母さんが赤ちゃんをだっこする」は非可逆文で、この段の条件に合わない。「先生が友達を呼ぶ」は、誰から見た友達かが分かりにくい。
- 直し方：説明を「おいかける：犬　にげる：猫」のようなラベルか矢印の図にする。だっこの文は可逆の組（女の子が男の子を呼ぶ）に替える。

**5. ⅩⅤ・ⅩⅧ の語と役割**
- b4b「川で散歩する」は不自然。「公園で」などにする。
- b2d「かみ（を）とかす」はかなのままで、紙と髪の区別がない。b3a の「かみを切る」（紙）とも混同する。disp で 髪・紙 を分けて表示する。
- 「どこに」を着点（b3e バスに乗る・いすに座る、ⅩⅧ e3c）と受け手（e3d 花に水をやる）にも使っている。受け手は「なにに／だれに」にする。
- Lv5 の言葉箱なし版でも て形（割って）が印刷されていて、て形を作る練習にならない。辞書形（わる）を示し、て形に変えて書かせる案がある。

**6. かなの表記と ⅩⅣ の判定の基準**
- 外来語がひらがなになっている：Ⅻ s3c とまと、Ⅶ ja_lv3 じゃむ、Ⅱ きゃべつ。
- ⅩⅣ f2h「ぱ で始まる」はこたえがほぼカタカナ語になる。
- ⅩⅣ f3h「い で終わる」は形容詞をいくらでも書けるうえ、とけい・せんせい（発音は長音）を正答にするかの基準がない。
- 直し方：外来語はカタカナで表示する。f2h には「カタカナで書いてよい」と README に書く。f3h は「名詞だけ」とし、長音の語の扱いを README に書く。

**7. 音韻の語の選び方**
- ⅩⅢ m2a くるま→まるく は活用形で、1つの語にならない。くるみ→みるく のような語に替える。
- ⅩⅦ の「゛をつける」で は行→ば行（ふた→ぶた、はね→ばね、ばら→はら）にする操作は、音声上は清濁の対ではない（/h/–/b/）。か→が とは別の文字の操作として扱う。
- Ⅶ Lv3 の促音の行（こ・っ□□、そ・っ□□、ちょ・っ□）は答えの例が副詞だけで、語彙の少ない子は答えを探せない。名詞がある行（せっけん・しっぽ・らっぱ）にしぼる。

## 6. 現場での懸念・子どもの反応の予想（すべて推論）
- ⅩⅥ Lv1・2 は、2問目あたりで並びの規則に気づく子が多いと思う。全問正答でも「助詞ができる」と判断しないよう、支援者に伝える必要がある。
- ⅩⅢ Lv4 の「道路から う」では、「う、ない」「どおろ？」と止まる子が多いと思う。
- ⅩⅢ・ⅩⅦ はルビを右から読めば解ける。読み上げずに使う教員が多い現場では、文字の課題になる。
- ⅩⅣ「い で終わる」では、ADHD の子が形容詞を並べ続けるかもしれない。
- ⅩⅧ は、教員が絵を用意できるかどうかの差が大きい。
- 中高生は「こいぬ」「わんわん」のような幼い語を嫌がることがある。Ⅳ・Ⅵ でしている題材の年齢への合わせ方を、音韻の語にも広げてほしい。
