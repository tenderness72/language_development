# ペルソナ④ 臨床心理士による評価（2026-10-27・18種全体）

## 1. 自己紹介と想定した場面
中村浩二（架空）です。臨床心理士・公認心理師になって10年目で、児童思春期のクリニックとスクールカウンセラー（SC）を兼ねています。ASD・ADHD の子の二次的な問題（自己肯定感の低下、不登校、不安）を多くみていて、WISC-V は日常的に取っています。
使う場面として、次の3つを想定しました。
- クリニックの個別面接で、ST や教員と役割を分けたうえで、語彙と文の課題を「話のきっかけ」として使う。
- SC として、別室登校の中学生に、教員が実施する課題を一緒に選ぶ。
- 検査を取る立場から、「この子は最近どのプリントをやったか」を確かめる。

見たもの：README.md、products.yaml、data/templates の18ファイル全部、評価レポート §3.5・§5.3・§17・§20〜§23、Wiki の関連ノート。PDF は12ページ前後を画像にして見ました（Ⅳ Lv3 p.4・p.12、Ⅵ Lv3 p.5、Ⅸ Lv2、Ⅺ Lv1 解答、ⅩⅢ Lv4、ⅩⅤ Lv2・Lv5 言葉箱なし、ⅩⅥ Lv3、ⅩⅧ Lv2 など）。

## 2. (1) ルーブリック（④ 臨床心理士）

前提（依頼者が追加）：このワークシートは言語発達だけを扱い、SST・感情の学習のワークシートは別にある。そのため、観点E（情動・社会性の学習としての意義）は範囲外とした。合計は A〜D の4観点（80点満点）を100点に換算した値で示す。感情語・対人の語は、次の2つの面からだけ見た。
- 言語の教材として、語の難しさが対象の発達水準に合っているか。
- 子どもの心理的な負担になるか。

## 4. 使いたいプリント上位3つ
1. **Ⅸ 仲間えらび・Ⅹ ベン図えらび**：○や線で答え、書く量が少ないので、失敗が目に見えて残りにくい。自信をなくしている子の最初の1枚に向く。Ⅹ は ASD の子の「1つの条件だけで分ける」傾向を観察する材料にもなる（SV-25）。
2. **ⅩⅦ ことばへんしん**：ことば遊びの形で、中高生でも幼く感じにくい（推論）。こたえが本当にある語になるので、手応えが大きい。口頭で出題する使い方もでき（README）、書くのが苦手な ADHD の子でも参加しやすい。
3. **ⅩⅤ 文を作ろう（3つの版）**：子どもが行き詰まったときに、どこまで戻せばよいかが README に書いてあり、自己効力感を守りながら難しさを調整できる。

## 5. 問題点（重い順）

**1. 検査と形の重なりがあるのに、README に注意書きがない（C）**
- どこで：
  - Ⅵ：どうぶつ・さかな・国
  - ⅩⅣ（f1a）・Ⅶ：か
  - ⅩⅢ：削除・逆唱の全レベル
  - ⅩⅥ Lv3：p3a「おとこのこ（が）おんなのこ（を）おす」
  - ⅩⅤ・ⅩⅧ：だれが・なにを・どうする の語連鎖
  - Ⅸ・Ⅲ：上位語と反対語
- なぜ：
  - 「さかな」「国」と語頭音「か」は、知的障害のある高等部生徒の語想起研究で使われたものと同じ（ND-01）。
  - ⅩⅥ p3a は、村尾（2022）の可逆・非基本語順の例文（GR-35）と、語も動詞も同じ。
  - 語流暢性は練習で得点が上がるとの報告がある（評価レポート §5.3 の Hurks 2012 ほか。Wiki 外で、私は本文を見ていない）。
  - この対象の子は、療育手帳の判定や就学・進路の判断で、くり返し検査を受ける。
  - WISC の「類似」や田中ビネーの項目と内容が重なるかは、照合していない（検査の機密性のため、ここには書かない）。
- 直し方：
  - README に3行を足す。「知能検査・言語検査を受ける予定の子には、検査の前に流暢性（Ⅵ・Ⅶ・ⅩⅣ）・音の操作（ⅩⅢ・ⅩⅦ）・格助詞（ⅩⅥ）のプリントを使わない」「使ったプリントを検査者に伝える」「プリントの成績を検査の代わりにしない」。
  - ⅩⅥ p3a は、研究の例文と違う語と動詞にする（例：おとこのこ が おんなのこ を よぶ）。

**2. Ⅳ Lv3・Ⅵ Lv3 の感情語・抽象語（A・B）**
- どこで：
  - Ⅳ Lv3：孤独（ヒント：一人）、後悔（反省）、別れ（卒業）、失敗、緊張、我慢、友だち（Lv3 は26語。PDF p.4・p.12）
  - Ⅵ Lv3：過去に関係することば、人を表すことば（性格）、体の感覚を表すことば（例：痛い）、危ないもの・こと
- (a) 言語の教材として、語が難しすぎる（B）
  - 抽象語の理解は、小6でも成人の水準に届かない（SV-04）。
  - 英語圏では、75%以上の子が意味を知る年齢は、regret（後悔）が11〜12歳、tense（緊張）が13〜14歳とされる（評価レポート §3.5。出典は SV-39 と同じ Baron-Cohen 2010）。
  - 精神発達が10歳未満という対象では、中心語の意味が分からないまま書けずに終わる。その結果、課題が関連語を思い出す練習ではなく、語を知っているかの確認になり、失敗が重なりやすい。
  - 直し方：Lv3 の中心語を、対象の発達水準で意味が分かりやすい語に絞る。たとえば、心像性が高い語や、場面や行動で示せる語（協力・仲直り・勇気・楽しみ。抽象語の獲得では感情価が足場になりうる：WL-14）にする。後悔・緊張・孤独・責任のように獲得の遅い語は外すか、別の版にする。
- (b) 心理的な負担（A）
  - 「反省」は、学校では「反省文」のように罰の文脈と結びつきやすく、自分を責める考えを呼びやすい（臨床的推論）。
  - 「孤独＝一人」は、一人で過ごすことを好む ASD の子に、一人でいるのは悪いことだという価値を伝えかねない（推論）。
  - 「別れ」「過去に関係することば」は、死別・離別の体験を呼び起こすことがある。「人を表すことば（性格）」では、自分が言われてきた悪口が出てくることがある（推論）。
  - 直し方：
    - ヒントを変える（後悔→「つぎはこうしたい」）。孤独・別れは中心語ごと外すか、個別の場で使う版に移す。
    - README に1行足す（方針で後回しの項目なので短く）：「書きたくないことは書かなくてよい。打ち明けられたときは、問い詰めずに受け止める」。

**3. 文の課題の人物と場面が偏っている（A・D）**
- どこで：
  - ⅩⅥ p3a：押すのは男の子、押されるのは女の子。穏やかな文脈がない。
  - ⅩⅥ p3c/d：「起こしているのは子ども。寝ていたのはお母さん」「遅れて来たのは私」
  - ⅩⅤ・ⅩⅧ：お母さんの文5つがすべて食事の支度か買い物（b2a・b3a・b4c・b5a・e3b）。お父さんは車を洗う・テレビを見る。
- なぜ：
  - 場面の多くが家族と家庭を前提にしている。
  - 子どもが親を起こす場面は、親の不調を世話している子（ヤングケアラー）には身近すぎることがある（推論）。
  - 性別による役割が固定して見える。
- 直し方：
  - p3a に「ブランコで」など、ふざけ合いではない文脈を書く。
  - 役割を入れかえた文を足す（おとうさんがカレーをつくる）。
  - 家族ではない人物を足す（店員さん・駅員さん・部活の先輩）。

**4. 文の課題と音韻の課題に、中高生が幼いと感じる語が多い（B）**
- どこで：
  - ⅩⅤ b1b、ⅩⅥ p2a：「ぼく が えほん を よむ」
  - ⅩⅤ b2a、ⅩⅥ p2a：「あかちゃん が ミルク を のむ」
  - ⅩⅤ b2c：うさぎ が にんじん を たべる
  - Ⅺ：「シールでもよい」
- なぜ：生活年齢の題材は Ⅳ・Ⅵ にしか足されていない（部活・スマートフォン・コンビニ）。受容語彙には生活年齢（経験）も寄与する（ND-04）。中高生は「幼稚だ」と感じると取り組まなくなる（臨床経験からの推論）。
- 直し方：語の難しさは変えずに、ⅩⅤ・ⅩⅥ・ⅩⅧ に生活年齢に合う文を足す。例：「スマホ で しゃしん を とる」「でんしゃ で がっこう に かよう」「コンビニ で おにぎり を かう」。

**5. 空欄が「できなかった」証拠として残り、始める基準と中止の基準もない（B）**
- どこで：
  - Ⅳ の教示「まわりの丸に書きましょう」（全レベル）
  - ⅩⅥ Lv3（4問のうち3問が非基本語順2文を含む）
- なぜ：
  - Ⅵ は「書ける分だけ」と直したのに、Ⅳ はそのままになっている。
  - ⅩⅥ Lv3 は、もともと正答40%未満の型を確かめる課題で（GR-35）、続けて練習させると失敗が重なる。
- 直し方：
  - Ⅳ の教示を「思いつくだけ書きましょう」にそろえる。
  - README に「ⅩⅥ Lv3 は確かめに使い、くり返しの練習にはしない」「前のレベルがおおむねできてから進む」と書く（指導水準から始める根拠：評価レポート §5.3 の Burns 2004。Wiki 外）。

**6. 効果と根拠の書き方（D）**
- どこで：
  - README「文のプリント」：「Shape Coding（Ebbels, 2007：RCT で大きな効果）」
  - README「誤り方を見る視点」：「分類で結びつける傾向（ASD で報告）か、抑制の弱さ（ADHD）」
  - README 冒頭の表の下（解答は Ⅰ・Ⅱ・Ⅲ・Ⅶ・Ⅸ・Ⅹ のみ）と、「印刷するとき」の解答の一覧
  - CLI の説明（`--type I〜VIII`、`--level 1〜3`、t1..t8）
- なぜ：
  - GR-36 の RCT では、効果は Shape Coding 群と意味指導群の両方に出ており（d>1.0）、Shape Coding だけが優れていたわけではない。対象は知的障害のない11〜16歳の SLI の生徒で、指導は個別の対面指導（30分×9回）だった。販売を考えているなら、プリントの効果と読み違えられるおそれがある。
  - 誤り方から障害を推し量る書き方は、1枚のプリントで子どもに診断名のような見方を当てはめることにつながる。
  - 解答のあるプリントの一覧が README の中で食い違っていて、CLI の説明は18種になる前のまま。買った人を迷わせる。
- 直し方：
  - 「Shape Coding（Ebbels ら 2007。個別指導の RCT で、意味指導群と同じように大きく伸びた）。このプリントの形での効果は確かめていない」と書く。
  - 誤り方の節に「診断や見立ての根拠にはしない」と足す。
  - README の古い記述を直す。

**7. ⅩⅧ の絵の扱い（A・B）**
- どこで：ⅩⅧ の全レベル（PDF は枠だけ。`data/images/` は README だけ）
- なぜ：
  - 絵がないまま配ると、子どもは何を書けばよいか分からず、つまずく。
  - 先生が子ども本人や家族の写真を使うと、プライバシーに関わり、感情の負荷も大きくなる（推論）。
- 直し方：README の ⅩⅧ の項に「絵を貼ってから渡す。子ども本人や家族の写真は使わない」と足す。

## 6. 現場での懸念と、子どもの反応の予想（すべて推論）
- **不登校の子**：Ⅳ Lv1 に学校の場面が9語ある（学校・教室・給食・運動会・遠足・部活・修学旅行・文化祭・中学校）。Ⅱ・Ⅵ にも学校の題材がある。別室登校の子にこれを最初に出すと、話がつらい話題に向かうことがある。最初は、テーマを子どもに選ばせるのがよいと思う。
- **ASD の中高生**：Ⅳ Lv3 の「孤独」に、文字どおり「へや」「イヤホン」と答えることがある。それを誤りとして扱わない構えが要る。ⅩⅥ Lv3 で状況の説明を読まずに常識で答えて間違えると、「ひっかけだ」と強く反発することがある。
- **ADHD の子**：ⅩⅦ・ⅩⅢ は短く、こたえが出ると気持ちよく、続けやすい。Ⅵ の10行は途中でやめやすい（5行版から始めるとよい）。
- **検査への不安が強い子**：名前欄・日付欄と解答ページがあるので、テストのように受け取ることがある。解答は大人が持ち、子どもには丸つけを見せない使い方もできる。
- **SC として**：Ⅵ Lv3 の「気持ちを表すことば」や Ⅳ Lv3 で、子どもがつらい体験を書くことがある。受け止める人がその場にいる形で使ってほしい（心理的な負担への配慮。感情の学習として使うことを勧める趣旨ではない）。
