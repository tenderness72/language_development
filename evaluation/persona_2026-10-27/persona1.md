## 4. 使いたいプリント上位3つ
1. **Ⅺ おとのかず**：見ただけで、何をするか分かります。○ぬりやシールで体を使うので、書くのが苦手な子にも渡せます。保護者にも「音に分ける練習」と一言で説明できます。
2. **ⅩⅤ 文を作ろう（3つの版）**：形の枠で役割が伝わり、同じ見た目のまま難しくできるので、誰にどの版を渡すか決めやすいです。解答に「ほかの組み合わせでも、自然な文なら正答」とあり、採点にも迷いません。
3. **ⅩⅦ ことばへんしん**：暇＋わり＝ひまわり のように、なぞなぞ感覚で解けて、勉強っぽさが少ないです（推論）。次点は Ⅸ（書かずに○だけで済む）です。

## 5. 問題点（重い順）
1. **README が現場の手引きとして読みにくい**（README.md 1〜30行ほか）
   - 何が：冒頭が「ジェネレータ」「量産して販売」「CLI」で始まり、3つの用途と「この子にはどれから」が最初に書かれていません。約3万字あり、専門用語（モーラ、撥音・促音、Shape Coding、可逆文、主題的・分類学的、DLD など）に説明がありません。
   - なぜ：手引きは README だけなので、ここで迷うと、誰にどのプリントを渡すかが決まりません。
   - 案：冒頭に1画面分の「現場向けはじめに」を置きます（用途ごとの最初の1枚・次の1枚・戻り先・読み上げで使う課題）。CLI とデータ編集は後ろへ回し、短い用語集を付けます。
2. **README の中の食い違い**
   - 何が：
     - 解答のある課題が、55行目では6課題、211行目では13課題と書かれています。
     - 186行目は「Lv1〜Lv3 のフォルダ」ですが、実際は Lv5 まであります。
     - CLI の表は `--type I〜VIII`・`--level 1〜3` で、見出しの「1〜4」と合いません。
     - 「難易度」の節は Ⅶ で終わっています。
     - 構成図が「t1..t8」のままです。
     - 一覧表で ⅩⅦ が ⅩⅤ より前にあります。
   - なぜ：どれが正しいか分からず、README 全体が信用されにくくなります。
   - 案：18種・5レベルにそろえて直します。
3. **ⅩⅥ の教示と空欄が合わない**（全レベル。t16_particles.py 14・16行、furigana.yaml 413・458行）
   - 何が：教示は「（　）に」ですが、空欄は□です。
   - なぜ：文字どおりに受け取る子は、「（　）がない」と止まるかもしれません（推論）。ⅩⅤ の助詞を書く版は「□に」と書いていて、表記がそろっていません。
   - 案：「□に」に直します。
4. **解答PDFの多くに「こたえ」の表示がない**
   - 何が：Ⅰ・Ⅱ・Ⅲ・Ⅸ・Ⅹ・Ⅺ・Ⅻ・ⅩⅥ の Lv1 解答の1ページ目に、「こたえ」「解答」の文字がありません（テキストを抽出して確認）。名前欄もあり、記入済みの問題用紙と同じ見た目です。ⅩⅤ・ⅩⅧ・Ⅶ には表示があり、課題によってまちまちです。
   - なぜ：急いで印刷すると、解答を子どもに渡したり、問題と取り違えたりします。
   - 案：帯の右に小さく「こたえ」と入れます。大人が使う紙なので、注記を書かない方針には当たらないと考えます。
5. **毎日使う課題のページが少ない**
   - 何が：ⅩⅢ・ⅩⅦ Lv2〜3・ⅩⅥ Lv4 は1ページ、Ⅸ〜Ⅻ は2ページです。一方、Ⅳ Lv1 は27ページあります。
   - 案：ⅩⅢ・ⅩⅦ・ⅩⅥ を1レベル3〜4ページに増やします。それまでは、README にくり返して使うときの目安（日をおく、語を口頭で替える）を書きます。
6. **ⅩⅧ の絵の内容が見つけにくい**
   - 何が：README は yaml の `scene:` を見るよう案内しています。実際には、解答PDFの枠の中に「（絵：子どもがコップのジュースを飲んでいる）」と書かれています。
   - なぜ：yaml を開けない人には、何の絵を用意すればよいか分かりません。
   - 案：README に「解答PDFの枠に絵の内容がある」と1行足すか、12場面の一覧を載せます。
7. **小さな表示の不ぞろい**
   - 何が：
     - Ⅰ の解答で、線が語に重なります（前回から継続）。
     - Ⅵ「たべるときに使うもの」だけが かな書きです。
     - 帯の番号が「Ｘ III」と間が空いて見えます。
     - Ⅷ に例がありません（前回から継続）。

## 6. 現場での懸念と子どもの反応（すべて推論）
- かなが読める子は、Ⅻ・ⅩⅢ を字を見て解き、「簡単」と言いそうです。読み上げで使うことを大人が知らないと、ねらいから外れます。
- ⅩⅢ Lv1 は8問すべてが「逆から言うと？」なので、ADHD の子は途中で飽きそうです。答えが言葉に変わる ⅩⅦ は喜ばれると思います。
- ⅩⅥ Lv3（語順と逆の文）は、知的障害のある中高生でも正答が40%未満だったとされます（README 106行の村尾, 2022。原典は確かめていません）。間違いが続くと嫌がる子が出そうなので、戻す目安がほしいです。
- ⅩⅧ の空の枠は、そのまま渡すと戸惑います。絵を貼る手間は、忙しい日には負担です。
- 保護者には、README の文をそのまま伝えられません。課題ごとに「何の練習か」が1行で分かる表があると説明しやすくなります。
- 高校生には、Ⅺ の○ぬりや、ⅩⅤ の「お母さん・りんご」が幼く感じられるかもしれません。
