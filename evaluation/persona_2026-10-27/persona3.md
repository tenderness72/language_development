# ペルソナ③ 臨床発達心理士による評価（2026-10-27・18種全体）

## 1. 自己紹介と、想定した使い方
山本 由紀（架空）です。臨床発達心理士として12年目で、市の発達相談センターで発達検査と支援計画の作成を担当し、学校への巡回相談もしています。
想定した使い方は次のとおりです。新版K式・WISC-V・LCSA・〈S-S法〉の結果から、言語のどの側面（音韻・語の想起・構文）が弱いかを見立てます。そのうえで個別の指導計画に「開始するプリントとレベル」を書き、通級・特別支援学級の担当者や保護者に渡して、学校と家庭で使ってもらいます。

見たもの：README.md 全文、products.yaml、data/templates の冒頭コメント（Ⅶ・Ⅸ・Ⅵ・Ⅺ〜ⅩⅧ）、全PDFのページ数、PDF 14ページ（Ⅱ Lv2、Ⅸ Lv1、Ⅺ Lv1、Ⅻ Lv2、ⅩⅢ Lv4、ⅩⅣ Lv1、ⅩⅤ Lv1／Lv2 言葉箱なし／Lv5、ⅩⅥ Lv3、ⅩⅦ Lv1、ⅩⅧ Lv1 の問題と解答）、評価レポート §17〜§23、改善記録 §4〜§6、Wiki のノート。

## 4. 使いたいプリント上位3つ
1. **ⅩⅥ 助詞を入れよう**
   - 村尾（2022）の課題の形と、知的障害のある中高生のデータにそのまま対応している（GR-35）。
   - Lv2 と Lv3 の差で、語順で答えているか、助詞で答えているかを見分けられる（GR-05・GR-35）。指導の教材であり、同時に見立ての材料にもなる。
2. **ⅩⅤ 文を作ろう（3つの版）＋ ⅩⅧ**
   - 〈S-S法〉の段階から開始レベルを決められる（GR-31）。
   - 構造の手がかりと語の手がかりを別々に外せる（ND-24）。この点を、個別の指導計画の短期目標に書き分けやすい。
3. **Ⅸ 仲間えらび → Ⅵ カテゴリー流暢性（同じテーマの組み合わせ）**
   - 「選べるが書けない」かどうかで、知識の不足か、思い出すこと（検索）のつまずきかの仮説を立てられる（ND-09・ND-01）。
   - 学校には「書けない＝知らない」と決めつけないよう説明できる。

## 5. 問題点（重い順）
1. **検査結果からプリントを選ぶ対応表がない**（README 63〜160行）
   - 何が問題か：根拠は README の各所に散らばっていて、「この結果ならここから」が一目で分からない。巡回相談の短い時間では使いにくい。
   - 直し方：1枚の表にする。列は次の4つ。
     - 前提となる力と、その確かめ方（例：〈S-S法〉の段階、LCSA の音韻意識・文表現〔GR-30〕、PA-06 の逆唱の課題）
     - 発達の目安（Wiki 番号。根拠がなければ「根拠なし」）
     - 開始するプリントとレベル
     - 戻り先
   - WISC の類似とカテゴリー流暢性の関連は、博士論文の要旨でしか確かめられていない（ND-06）ので、対応表には入れないほうが安全。
2. **かなが読めることと、2語文を練習すること：発達水準のずれ**（README 冒頭、ⅩⅤ Lv1・Lv2）
   - 何が問題か：定型発達では、ひらがなの大半が読めるのは年長（RW-01）で、2語連鎖の表出は2歳前半（GR-31）。かなが読めるのに2〜3語文の練習が要るのは、限られたプロフィールの子だと推測される。たとえば次の子どもである。
     - 表出の統語だけが遅れる子（ダウン症：ND-20）
     - 読字が理解より進んでいる子（ハイパーレクシア型の ASD：ND-18）
     - 語を思い出すことが弱い子（ND-24）
     ここは推論である。
   - 直し方：README に「どんな子が ⅩⅤ Lv1・Lv2 の対象になるか」を書く。あわせて、話しことばで2語連鎖がまだ出ていない子では、紙より先に語彙（特に動詞）を確かめると書く（GR-32・GR-33）。
3. **記録・通過基準・やめどきがない**（方針で後回しの項目）
   - 何が問題か：次のレベルに進むか、1つ前の版に戻るかを決める基準がない。
   - 直し方：README に「2回続けて8割で次へ」のような目安を1行書く。この数値は根拠のない仮の基準と明記する。
4. **根拠のない段階づけが、そうと書かれずに残っている**
   - 該当するもの：
     - Ⅻ の語頭 → 語尾 → 語中（XII_sound_search.yaml の冒頭。Wiki に直接比べたノートはない）
     - ⅩⅣ Lv3 の語尾（XIV_sound_fluency.yaml。「語尾音の抽出は語頭音より遅い」の根拠に PA-02 を挙げているが、PA-02 にその比較はない）
     - Ⅺ Lv2 の濁音の段
     - ⅩⅦ のレベル全体と、ⅩⅦ を ⅩⅢ の後に置く順（公開教材の構成に合わせたもの）
     - ⅩⅤ Lv3 で「で」の場所と道具を同時に入れること（ND-20）
     - ⅩⅧ Lv1 の助詞の印刷（ⅩⅤ Lv1 は助詞なし）
   - 直し方：README と YAML の冒頭に「根拠なし（作成者の判断）」と書く。ⅩⅧ Lv1 は助詞を印刷しない形にそろえるか、そろえない理由を書く。
5. **生活の場面（ICF の活動・参加）へのつなぎがない**
   - 何が問題か：紙の上で文が作れても、学級や家庭の会話で使うようになるとはかぎらない。
   - 直し方：ⅩⅧ の絵として、本人の学校行事や日課の写真を使う例を README に書く。ASD の子では、写実的なカラー写真のほうが実物への般化がよいという報告がある（ND-17）。あわせて「ⅩⅤ で使った動詞を、その週の日課の中で言ってもらう」といった家庭向けの例を1〜2行書く。マトリックス訓練の考え方（ND-23）で、練習していない組み合わせを確かめる問題を作る案もある。
6. **README が関係者に渡せる形でなく、古い記述が残る**
   - 古い記述の例：
     - 55行「解答面は Ⅰ・Ⅱ・Ⅲ・Ⅶ・Ⅸ・Ⅹ のみ」が、211行の一覧と食い違う。
     - 186行「Lv1〜Lv3 のフォルダ」（ⅩⅢ・ⅩⅤ・ⅩⅥ には Lv4・Lv5 がある）。
     - 236・237行のオプションが「I〜VIII」「1〜3」のまま。
     - 334行「t1..t8 8テンプレート」（実際は t1〜t18）。
     - IX_category_choice.yaml 4行「（ページに明記）」（PDF には書いていない）。
   - 直し方：古い記述を直す。支援者向けの1〜2ページ（はじめる順、使い方、戻り先）を、開発・販売向けの説明から分ける。
7. **くり返しの量の偏り**
   - 何が問題か：ページ数に大きな差がある。
     - 少ないもの：ⅩⅢ は各レベル1ページ（8問）、ⅩⅦ Lv2・Lv3 と ⅩⅥ Lv4 は各1ページ、ⅩⅧ は各レベル4文。
     - 多いもの：Ⅳ Lv1 は27ページ、Ⅵ Lv2 は26ページ。
     音韻と構文の課題では、練習の前後に、同じ形で別の語を使った確認の問題（並行版）を作れない。
   - 直し方：ⅩⅢ・ⅩⅦ・ⅩⅧ に問題を足して、少なくとも2つの版が作れるようにする。

## 6. 現場で使うときの懸念・子どもの反応の予想（推論）
- 高校生に Ⅺ Lv1（犬・魚・机）を出すと、「子どもっぽい」と嫌がるかもしれない。知的障害のある年長の生徒は、精神年齢から予想されるより受容語彙が多いことがある（ND-04・ND-12）。音の数が同じ課題なら、年齢に合った語を選んでもよい。
- ⅩⅧ は、絵がないと枠だけになる。教員が忙しいと使われないかもしれない。
- ⅩⅧ（e3c 自転車に乗る、e3d 花に水をやる）と ⅩⅤ Lv3（バスに乗る）では、「自転車」「花」「バス」の枠の名前が「どこに」になっている。どれも場所ではない（花は水をやる相手）ので、枠の名前と中身が食い違い、ASD の子が戸惑うかもしれない（XVIII_picture_sentence.yaml、XV_sentence_build.yaml 68行）。
- ⅩⅥ Lv3 は、状況の説明文を読む量が多い。読むのが遅い子は、助詞を考える前に疲れてしまうかもしれない。説明文を大人が読み上げれば、この負担は減る。
- 保護者が README を読んで、自分でレベルを選ぶのは難しいと考える。専門職が開始のレベルを指定して渡すのが現実的である。

## 7. 確かめられなかったこと
- 子どもに使ってみた結果はない。発達の目安はどれも、定型児か小さな標本のデータである。
- 新版K式・WISC-V の指標とプリントの対応を示すノートは、Wiki にない。LCSA は、GR-30 に書かれている下位検査しか確かめていない。
- PDF は14ページしか画像で見ていない。ほかのページは、ページ数とデータで確かめた。
- ⅩⅧ に絵を入れたときの見た目は確かめていない（data/images には README だけがある）。
- 生成記録（manifest）の中身は確かめていない。
