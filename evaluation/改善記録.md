## 1. ⅩⅤ 言葉箱なし版（優先度1）

**なぜ1位か**：用途③（二語文・三語文の生成）の中心なのに、今の ⅩⅤ は「言葉箱から選んで並べる」課題だけで、
語を自分で思い出して文にする段がなかった。知的障害児の2語文形成には「2語構造の習得」と「語の喚起」の2つの側面がある
（ND-24）。言葉箱あり版は前者しか練習できず、生成（表出）の課題として半分しか機能していなかった。既存の問題と描画をそのまま
使えるので、手間に比べて効果が大きい。

**考えた案**
- (a) 枠だけを出し、語をすべて自分で考えさせる：手がかりがなく、何の文を作るかが決まらない。この子たちには負荷が大きすぎ、
  失敗が続きやすい。
- (b) 名詞（だれが・なにを）を印刷し、動詞を考えさせる。
- (c) 動詞（どうする）だけを印刷し、ほかの項を考えさせる。
- (d) 絵を手がかりにする：紙の線画では意味が一つに決まりにくい。記号接地は紙で扱わない方針でもある。

**採った案と理由**：(c)。
- 動詞は、どの項（だれが・なにを・どこで）が必要かを決める。動詞を示せば、作る文の骨組みが決まり、そのうえで項に入る語を
  自分で思い出す課題になる。動詞の語彙は文法の発達を予測するとの報告がある（GR-33）。そこで、子どもが自分で出す負荷は
  名詞の側に置いた。
- (b) は、動詞を思い出す課題になる。こちらも必要だが、動詞の想起は名詞より難しい。最初の自由想起版としては (c) を先にした（推論）。
- 問題は言葉箱あり版と同じものを使う。同じ文型で「選ぶ → 自分で出す」と進めるためである。
- 解答は「こたえの例」とする。自然な文ならどれも正答。

**実装**
- `t15_sentence_build.py`：`no_bank: true` のとき言葉箱を描かず、「どうする」の枠にだけ語を印刷する。
- 教示「書いてある言葉に合う言葉を考えて、あいている枠に書き、文を作りましょう。」
- `products.yaml` の ⅩⅤ に variant `言葉箱なし` を追加した。

**限界**
- Lv3（4枠のうち3枠を自分で出す）は負荷が高い。合う語が出ないときに言葉箱あり版へ戻すか、大人が2〜3語から選ばせることを README に書いた。
- (b) の版（動詞を思い出す版）は作っていない。

## 2. ⅩⅥ 問題の追加（優先度2）

**なぜ2位か**：各レベル2問（1枚）しかなく、同じ問題を繰り返すと、文を読まずに答えを覚えて解けてしまう。
助詞の課題では、できたかどうかを語順の手がかりと切り分けて見る必要がある（GR-34・GR-35）。そのためには問題の数が要る。
データを足すだけで済む。

**考えた案**：各レベルに2問（8文）ずつ足す。Lv3 は、(a) 新しい場面を8つ作る案と、(b) 同じ4つの場面を語順を入れかえて
2回出す案を比べた。

**採った案と理由**
- Lv1・Lv2：既存の文と、ⅩⅤ の文と重ならない、非可逆で基本語順の文を足した。村尾（2022）で中高生の正答が高い型で、ここで成功させる。
- Lv3：(b)。p3c と p3d は同じ4場面で、各問を「基本語順2文＋入れかえ2文」にした。同じ意味の文が語順だけ違って出るので、
  語順で当てていないかを確かめやすい。
- Lv3 の場面のうち2つは、ありそうな方とは逆にした。「妹がお兄さんを助ける」「子どもがお母さんを起こす」である。
  状況の説明を読まずに、常識（お兄さんが助ける・お母さんが起こす）で「が」を決めていないかを見るためである。
  先行文脈で「を」の理解が上がるという報告（GR-34）に沿って、説明を先に読む形はそのままにした。

**限界**
- 「待っているのは友達。遅れて来たのは私。」は、受け身にすると不自然になる場面なので、説明の言い方を変えた。
  説明文の書き方は、場面ごとにそろっていない。

## 3. 「属性＋事物」と助詞「に」（優先度3）

**なぜ3位か**：〈S-S法〉の語連鎖の型には「属性＋事物」がある（GR-31）。また、助詞「に」は日常の文（学校に行く・いすに座る）に
欠かせない。どちらも今のプリントになかった。ただし発達の順序の根拠が弱い。そのため1・2より後にした。

**考えた案（属性）**
- (a) 「おおきい りんご」のような2語の名詞句を作る。
- (b) 文の中に入れる（どんな＋なにを＋どうする：あかい くつを はく）。

**採った案と理由（属性）**：(b)。ⅩⅤ は「文を作る」課題で、名詞句だけでは文にならない。教示とも合わない。
3語にしたので Lv2（3語・助詞なし）に置いた。「どんな」の枠は平行四辺形にした。Shape Coding（GR-36）の原典には形容詞の形がない。
既存の4つの形（楕円・四角・六角形・破線）と見分けやすい形を、このプリントで決めた。

**考えた案（に）**
- ⅩⅤ に「どこに」の役割を足す。
- ⅩⅥ のどのレベルに入れるか。(a) Lv2 に混ぜる。(b) 新しい Lv4 にする。

**採った案と理由（に）**
- ⅩⅤ Lv3 に「どこに」（破線。なくても文になる項として「どこで」と同じ扱い）を足した。Lv3 は助詞を印刷する。助詞を書く版の教示は、
  そのページで使う助詞（が・を・で・に）だけを並べるように変えた。
- ⅩⅥ は (b) Lv4 にした。(a) では、Lv2 の「が」「を」の2択に「に」が混ざり、同じレベルの中で選択肢の数が変わってしまう。
  Lv4 は非可逆・基本語順の文だけで、「が＋に」と「が＋に＋を」で作った。
- ⅩⅥ Lv4 の教示は「『が』『を』『に』から1つ選んで、（　）に書きましょう。」にした。「（　）に『が』…」の形だと、
  教示の「に」と答えの「に」が並んで紛らわしいため。

**根拠と限界（重要）**
- 「に」の習得が「が」「を」より後だという日本語の研究は、Wiki では確認できていない。そのため Lv4 は「選ぶ助詞が3つに増える」
  という課題の負荷の順で置いた。README には「Lv2 のあとなら Lv3 と Lv4 はどちらが先でもよい」と書いた。
- 〈S-S法〉の型ごとの通過年齢（属性＋事物は何歳か）は、読めた抄録では確認できなかった（GR-31）。そのため「どんな」を Lv2 に置いたのは、
  語の数（3語）による配置である。
- Shape Coding では必須の項を実線、なくてもよい項を破線で示す（GR-36）。「どこに」はすべて破線にしたが、
  「コップにジュースを入れる」の「に」のように、動詞によってはほぼ必須の項になる。ここは単純化している。

## 4. 関連語の想起：選ぶ → 手がかりつきで出す → 自由に出す（優先度4）

**なぜ4位か**：用途②（関連語を引き出す力）のために、選ぶ版（Ⅸ・Ⅱ）と書く版（Ⅵ・Ⅳ）はそろっていた。
ただし、その間をつなぐ段（手がかりを少しずつ減らす段）と、どのプリントを組み合わせるかの案内がなかった。新しい課題を作るより、
既存の課題の組み合わせと、手がかりの段を1つ足すことで済む。それでこの位置にした。

**考えた案**
- (a) README に「同じテーマの組み合わせ表」を足すだけ。
- (b) Ⅵ にヒント版を足す。ヒントの種類は、(b1) 語頭の文字、(b2) 下位カテゴリー（「ペット」「動物園」など）、(b3) 文字数（マス）を比べた。
- (c) Ⅸ の選んだ語をそのまま書き写させる：写すだけになり、思い出す課題にならない。

**採った案と理由**：(a)＋(b1)。
- 知的障害のある高等部生徒では、カテゴリーを手がかりにした想起は知能の影響を強く受ける。一方、語頭音を手がかりにした想起は
  受けにくく、カテゴリーから外れる誤りが多いと報告されている（ND-01）。また、DLD・読み書き障害の意味流暢性の低さは、
  意味ネットワークの貧弱さより検索の遅さで説明されるとの報告がある（ND-09）。そこで「カテゴリー」と「最初の文字」の2つの
  手がかりを重ね、検索の範囲を狭めることにした。
- ヒントの文字は、同じカテゴリーの Ⅸ で仲間だった語の最初の文字にした。Ⅸ で見て選んだ語を、手がかりつきで自分で思い出す形になる。
  ただし、その文字から始まる仲間の語ならどれでも正解とした。
- (b2) は Ⅵ のカテゴリー自体が下位カテゴリーを含むので重なる。(b3) は Ⅶ と同じ形になり、音韻の負荷が加わる。
- Ⅱ → Ⅳ（場面の関連語）は、Ⅳ の中心の丸が自由想起の形なので、文字ヒントを足さず、組み合わせ表だけにした。

**実装**
- Ⅵ のデータに `hints`（と、元にした Ⅸ の id `hint_from`）を8カテゴリー分足した。
- テンプレートは `show_hints: true` のとき、線の初めに文字を印刷し、教示の下に「線の初めの字は、言葉の最初の文字です。」と書く。
- ヒントのあるカテゴリーだけで PDF を作れるよう、`products.yaml` の variants に `only:` を足し、生成プログラムを対応させた
  （枚数も絞ったあとの問題数から決める）。

**限界**
- 3段の組み合わせで語想起が伸びるかは確かめられていない（推論）。
- ヒント版は8カテゴリーだけ（Ⅸ が8カテゴリーのため）。
- 例の語と同じ語（うさぎ・りんご など）はヒントから除いた。

## 5. ⅩⅢ Lv4：特殊音節の削除（優先度5）

**なぜ5位か**：用途①（音韻意識）のプリントは Ⅺ〜ⅩⅣ・ⅩⅦ でかなりそろっていた（§20.2 で音韻意識は3つの用途のうち最も高い評価）。
残る課題は、特殊音節（っ・ん・のばす音）を1つの音として操作する段だけだった。

**考えた案**：(a) ⅩⅢ Lv3（まんなかの音をとる）に混ぜる。(b) Lv4 として分ける。

**採った案と理由**：(b)。特殊音節を含む語を、モーラ単位で分けられるようになるのは仮名読みの習得に伴ってで、促音が最も遅い（PA-05）。
まんなかの音をとる課題とは難しさの理由が違うので、レベルを分けて、README で Ⅺ Lv3（特殊音節を含む語の音の数）の後に使うよう書いた。

**語の選び方**：こたえが意味のある言葉になるもの（ご指示：ⅩⅢ のこたえは意味のある言葉に）。
- 当初案の「せっけん → せけん」は、こたえの語が抽象的なので「ねっこ → ねこ」に替えた。
- 同じく「きって → きて」は、こたえが名詞でないので「さっか（作家）→ さか（坂）」に替えた。
- 「こんや → こや」「ふうせん → ふせん」は、「てんき → てき」「どうろ → どろ」に替えた。より身近な語にするためである。
- 結果：根っこ・作家・漢字・空気／たんす・天気・道路・勇気（っ×2、ん×3、う×3）。

**限界**：のばす音を「う」の字で示している。字を見て消せば解けてしまう。音の操作として練習するときは、README の
「文字を見ずに答える使い方」（大人が読み上げ、紙の語を隠す）で使う。
