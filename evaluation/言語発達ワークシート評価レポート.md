## 1. 評価の方法

### 1.1 手順

1. YAMLデータ（Ⅰ〜Ⅷの全項目）を1項目ずつ点検した。語の正確さ、関係の妥当性、正解が一意か、レベル付けが整合しているかを見た。
2. 生成済みPDFを画像にして確認した。レイアウト、教示文、子ども向けの表示を見た。
3. manifest を集計し、パック内の重複を検出した。
4. 生成コードを確認した。レベルが実際にどう処理されるか、モーラをどう分割しているかを見た。
5. 文献の知見を各視点のルーブリックに対応させて採点した。

## 2. 直接確認した具体的な問題（データ・実装）

文献に頼らず、教材そのものを点検して確認した事実です。§5・§6の採点の前提になっています。

### 2.1 事実誤り・不自然な語（Ⅲ・Ⅰ）

| 箇所 | 現状 | 問題 | 修正案 |
|---|---|---|---|
| Ⅲ animal_home | はち→**すばこ** | 巣箱は鳥のためのもの。事実として誤り | はち→はちのす |
| Ⅲ animal_home | とり→**す**／くも→**くもの巣** | 「す」と「くもの巣」が意味の上で重なる | 語の選び直し |
| Ⅲ part_use | 鼻→**におう** | 「におう」は物がにおいを発すること。感覚器のはたらきとしては「かぐ」 | 鼻→かぐ |
| Ⅲ instrument | ピアノ→**おす**／ギター→はじく | ピアノは慣用的に「ひく」。ただし「ひく」はギターにも当てはまるので、正解が一つに決まらなくなる | ピアノかギターのどちらか一方だけを残し、その正答を「ひく」にする |
| Ⅲ animal_baby | ライオン→**こライオン** | 実在しない語。しかも全問が「こ＋左の語」なので、意味を考えなくても音の規則だけで解ける | 関係を変える（例：かえる→おたまじゃくし、にわとり→ひよこ） |
| Ⅲ weather_item | 風→ウインドブレーカー／くもり→うわぎ | 「雪→手袋」との区別が弱く、関係の必然性も低い | 差し替え |
| Ⅲ season_thing | 梅雨 | 季節（春夏秋冬）と同じ水準の語ではない | 注記するか、関係名を「季節・時期」にする |
| Ⅰ tree_paper | 木→きる→板→**けずる→紙** | 紙の作り方として事実と違う（紙はパルプから作る） | チェーンを作り直す |
| Ⅰ grape_wine | ぶどう→つむ→しぼる→**おく**→ジュース | 「おく→ジュース」のつながりが成り立たない（id が示す「ワインを寝かせる」の名残か） | 作り直す |
| Ⅰ rain_use | …→さす→**使う** | ゴールが汎用的な動詞で、連想のゴールとして弱い | ゴールを名詞に |

### 2.2 閉じた課題なのに正解が一意でない（Ⅰ）

README は「Ⅰ・Ⅱ・Ⅲは一意に解けることを保証」と書いていますが、自動チェックが見ているのは**正解語とダミー語が同じ文字列で重複していないか**だけで、**意味の上で別の経路が成り立つかどうか**は検査していません。

- **cloud_umbrella（Lv3）**：正解は くも→ひろがる→ゆうだち→ぬれる→タオル。しかし **くも→きえる→はれ→かわく→タオル** も同じくらい筋が通る（きえる／はれ／かわく はいずれもダミー語）。
- **grape_wine**：col4 のダミー「わる」は「ジュースを割る」という連想が成り立つ。
- **rice_onigiri**：col4 のダミー「やく」は「焼きおにぎり」の連想が成り立つ。

教示が「関係が深いと**思う**ことばを」と主観を認めているのに、解答PDFは正解を一つに決めています。この食い違いは、別の筋の通った答えを出した子どもを「誤り」にしてしまうおそれがあります。成人の自由連想でも反応は非常に分散します（佐藤・坂元：「赤」への反応は577種類、同じ語を答えた人は平均1.95人）。

### 2.3 README の保証と実際の出力の食い違い

| 主張（README） | 実際 |
|---|---|
| 「パック内で問題・使用語の重複なしを保証」 | **放射状連想 Lv2**：「お正月/おもち」「駅/電車」が**まったく同じ問題として2回**、「朝」「病院」も中心語が重複（計4件）。**カテゴリー流暢性 Lv2**：「スポーツ」「花」が2回ずつ。さらに表記違いの実質的な重複（文房具/ぶんぼうぐ、体の部分/からだのぶぶん、鳥/とり、魚/さかな、虫/むし）。**ベン図パック**：「丸いもの」が2回。重複は id 単位でしか管理されていないのが原因 |
| 「Ⅶ：レベル＝モーラ数の上限」 | コードは `MORA_ROWS = [2, 3, 4, 5]` で固定されており、**レベルを変えてもマス目は変わらない**。データの Ⅶ 項目は Lv2/Lv3 だけで、`products.yaml` の「音韻パック level 1」に当てはまる項目は0件。自動的に全レベルに広げて出題されている |
| 難易度（自由記述は抽象度で調整） | Ⅳでは同じ「中心語＋ヒント」が Lv1 と Lv2 の両方にある（海/波、冬/雪、誕生日/ケーキ、駅/電車、お正月/おもち）。Ⅵでも「色」「国」「スポーツ」などがレベルをまたいで重複。レベル付けの基準が一貫していない |

### 2.4 教示・表示の問題

- **Ⅶの教示**：「小さい『ゃ・ゅ・ょ』は1マスに入れても**構いません**」。モーラの規則では、拗音は2文字で1拍なので、1マスに入れるのが**正しい**。任意ではない。さらに促音「っ」・長音・撥音「ん」がそれぞれ1マスであることに触れていない。
- **Ⅶの解答PDF**：モーラ数ごとに例を**1語だけ**載せている。自由産出の課題なのに正解表のように見え、保護者が他の答えを誤りと判断するおそれがある。例に「きりんさん」「とらのこ」など語として不自然なものがある。
- **ふりがなのない漢字**：聴診器・看護師・診察・司書・貸し出し・牧草・郵便局・小包・美容師・写真家・鳩 など。課題の出来が漢字の読みに大きく左右される。同じ語が表によって「りんご」「果物」のように表記揺れしている。
- **レイアウト**：Ⅰ・Ⅲ・Ⅷで「問題1」の見出しが教示文の行と重なっている（生成PDFで確認）。
- **Ⅷ「小さいもの／むし」**：虫の大半は「小さいもの」に含まれるので、「右だけ（小さくない虫）」の領域がほぼ空になる。一方の属性がもう一方をほぼ包み込む組み合わせは、ベン図の論理構造として不適切。
- **Ⅵ Lv3「反対の意味のことば」「似た意味のことば」**：仲間の語を列挙する課題ではなく、対の語を作る課題なので、1行1語の書式に合わない。「似た意味のことば（例：悲しい）」は、何と似た意味の語を書けばよいかが分からない。

### 2.5 優れている点（実装）

- 語データを YAML に切り出しているので、専門職が後から語を差し替えられる。臨床で一人ひとりに合わせるうえで大きな利点。
- seed で再現できる、manifest で出題を記録できる、枠からのはみ出しを自動で検査する、といった品質管理の仕組みが整っている。
- モノクロ前提、A4に2問という分量、名前・日付欄がある。学校や療育の現場で扱いやすい。
- 子ども向けの表示名（「ことばのペアをつくろう」など）と臨床名（manifest のみ）を分けている。
- 時間制限がない（ADHD・ASDの想起の遅さへの配慮として妥当）。

## 3. 評価の前提となる主な知見（視点ごとの採点根拠）

### 3.1 紙のワークシート単体の効果研究はない

- **Drive・国内・海外のどの調査でも、ワークシート形式の語想起課題の訓練効果を直接確かめた研究は見つからなかった。**
- 子どもの喚語困難に効果が示された介入は、ほぼすべてが**STによる対面・直接の意味療法や音韻療法**である（Best et al., 2018 RCT；Best et al., 2021；Ebbels et al., 2012 RCT；Bragard et al., 2012）。
- 般化は限られている。
  - Best et al.（2018）：訓練語は大きく伸びたが、非訓練語はほとんど変化しなかった。
  - Ebbels et al.（2012）：意味流暢性と談話は改善しなかった。
  - Wilson et al.（2015）：般化は同じ意味領域の中にとどまった。
- 国内でも、子どもの意味ネットワーク訓練の効果研究は見つからなかった。石井（2024）の SFA・PCA の総説は、成人の失語症が対象である。
- Drive の文献も一貫している。課題の中では伸びても、日常への般化は起きにくい（島宗・細畠 2008；湯澤 2019；室橋 2015「日常生活における改善がみられなければ実践的には意味がない」）。

### 3.2 閉じた課題（再認）と開いた課題（再生）は別の力を測る

- 喚語困難は、定義からして「分かるが言えない」状態である。Ⅰ・Ⅱ・Ⅲ・Ⅷ（選択式）ができても、Ⅳ〜Ⅶ（産出）ができるとは限らない。
- 島宗・細畠（2008）では、感情語をカードで選べても、音声では答えられなかった。
- Ⅲ（5対5のマッチング）は消去法で解けるので、正答数が知識を過大評価する。

### 3.3 カテゴリー流暢性の国内基準と、時間制限なし・筆記版の問題

- **村井ら（2004）**：小学生151名、口頭・各1分の基準値。小1の平均は、動物 8.58±3.31、乗り物 6.97±2.36、「か」 5.22±1.94。
- Ⅵは「筆記・時間制限なし・約10行」なので、この基準とは**比べられない別の課題**である。書字の困難が成績に混ざる。
- **国立国語研究所（1981）『幼児・児童の連想語彙表』**の公開データを調査担当が集計した値では、「家具」は小1でも48%が無反応、道具・楽器・植物は就学前に無反応が多い。原著の統計値ではなく、標準値としては使えないが、カテゴリーの具体→抽象の並べ方の根拠にはなる。
- 語流暢性は、反復や方略の練習で得点が上がる（Hurks, 2012；Arán Filippetti et al., 2024）。

### 3.4 日本語のモーラ意識と特殊音節

- 拍の定義は「仮名1文字（拗音では2文字）」（原, 2001）。拍数と文字数がずれるのは**拗音を含む語だけ**（はくちょう＝4拍・5文字）。
- 特殊拍の自覚は5歳前後から伸びる（伊藤・辰巳, 1997）。
- 小1でも、促音・拗音の読み書きは長音・撥音より難しい（浜田・宇野, 2021）。
- 年長児の特殊表記語の音読正答率は、長音 59.6%、拗長音 42.8%（太田ら, 2018）。
- 東京都教委のマニュアル（2017）と国内の教材（村井・中尾, 2010）は、直音 → 撥音・促音 → 拗音（高頻度→低頻度）のように、**種類ごとに段階を分けて**扱っている。

### 3.5 抽象語・感情語の獲得時期

- 学習指導要領（平成29年告示）国語では、「抽象的な概念を表す語句」は**中学校第2学年**の事項。
- 小学生の標準抽象語理解力検査（SCTAW）では、小6でも成人に届かない（春原ら, 2007）。
- 英語圏のデータ（Baron-Cohen et al., 2010）で、その年齢帯の75%以上が意味を知っている時期は、regret（後悔）が11〜12歳、relief（安心）・responsible（責任）が9〜10歳、tense（緊張）が13〜14歳。4〜11歳は親・教師の報告による。日本語での語ごとの年齢基準は見つかっていない。
- 国内では、感情語の区別がはっきりしてくるのは5歳前後（浜名・針生, 2015）、心的な手がかりに注目するのは9歳ごろから（塚本, 1997）。

### 3.6 感情語教材と開示・安全

- 文部科学省「生命（いのち）の安全教育 指導の手引き（改訂版）」は、性的グルーミングを「信頼関係を装い」「秘密の共有などで心の距離を縮める」行為として説明している。
- 子ども向けの安全教育は「いやな気持ちになる秘密は話そう」と教える（NSPCC）。
- 予防教育は開示を増やしうるので（Walsh et al., 2015, Cochrane）、受け止める大人の準備が必要になる。

### 3.7 保護者が実施する介入のエビデンスが当てはまる範囲

- 効果が確かめられているのは、**保護者が訓練を受け、日常のやりとりで応答的な方略を使う**介入である（Roberts & Kaiser, 2011；Heidlage et al., 2020。後者はASDでは有意でない）。
- 家庭プログラムでは、保護者への直接訓練と十分な量が要件になる（Tosh et al., 2017）。
- **プリントを家庭で解かせる形式の効果の根拠にはならない。**

**STとしての所見**

- **Ⅶは最も根拠を積み上げやすい型**です。改善の方向ははっきりしています。
  - Lv1＝直音のみの2〜3拍、Lv2＝撥音・長音を含む、Lv3＝促音・拗音を含む、という段階化（伊藤・辰巳 1997；浜田・宇野 2021；村井・中尾 2010）。
  - 教示に「1マス＝1拍。『きゃ』のような小さい字のつく音は2文字で1マス、『っ』『ー』『ん』はそれぞれ1マス」と明記する。
  - 拍の確認は手拍子やおはじきで行い、口頭での解答も認める（宇野ら 2015；海津ら 2008 の動作化・視覚化）。
- **Ⅱが最も完成度の高い型**です。改善点は、ダミー語の意味的な近さで難易度を調整することと、関連語に関係のラベル（どこにある／何をする／どんな様子）を付ける発展版を用意することです。後者は意味素性分析の考え方に近づけます。
- **Ⅰは、正解が一意であることと、関係の種類を揃えることの両方に問題があり、最も手直しが必要**です。「一緒に使う語（連辞関係）」と「同じ仲間の語（範列関係）」（小寺 1999 の S-S 法の観点）をレベルで分け、名詞と動詞が混ざるチェーンは上位レベルに回すことを勧めます。
- **Ⅵは「評価には使えない練習用」と明記**し、カテゴリーを NINJAL の集計に沿って具体→抽象に並べ直すこと、「反対の意味のことば」を別の型に分けることを勧めます。

## 7. 改善提案（優先度順）

### 優先度A（出荷前に必須）

1. **Ⅳ Lv3のヒント文を差し替える**（§5.3-A）。
2. **語データの誤りを直し、正解が一意になるよう点検する**（§2.1・§2.2）。閉じた課題は、複数の専門職（STなど）が「別の筋の通る経路がないか」を確認する手順を加える。
3. **Ⅶの教示を正しくする**：「1マス＝1拍。小さい『ゃゅょ』は前の字と同じ1マス。『っ』『ー』『ん』はそれぞれ1マス」。解答PDFは「答えの例（ほかにもたくさんあります）」と明記する。
4. **重複の管理を id 単位から「中心語／カテゴリー名（表記を統一したもの）」単位に変える**。表記揺れ（文房具/ぶんぼうぐ）も同じものとして扱う。
5. **Ⅷの組み合わせを点検する**：一方の属性がもう一方をほぼ包み込む組を除く。

### 優先度B（専門職向け教材として必要）

6. **大人向けの手引きを付ける**。記載する内容：
   - 対象年齢・前提となる力
   - 各型のねらいと限界（評価には使えない、効果は未検証、治療・療育の代わりにはならない）
   - 手がかりの段階の例：意味の手がかり（「どこにある？」「何をするもの？」）→ 語頭音の手がかり → 選択肢
   - 答えの受け止め方の例
   - 1回の目安時間とやめどき
   - 感情語を扱うときの配慮（§5.3）
   - 検査を受ける前の使用についての注意
7. **レベルを発達データに基づいて作り直す**。
   - Ⅶ：直音 → 撥音・長音 → 促音・拗音（§5.1）。コードでもレベルごとにマス目・語頭音を実際に変える。
   - Ⅵ：NINJAL の集計に沿って具体 → 抽象（動物・果物 → 道具・楽器 → 抽象カテゴリー）。
   - Ⅳ・ⅥのLv3：「高学年〜中学生向け」の別シリーズに分ける。
8. **読み書きの負荷を下げる**。すべての漢字にふりがなを付けるか、ひらがなだけの版を作る。大人が読み上げて口頭で答える版を公式な使い方として示す。
9. **記録欄を付ける**：援助の量（なし／意味の手がかり／音の手がかり／選択肢）、所要時間、気づいたこと。STや心理職が経過を追えるようにする。

### 優先度C（付加価値）

10. 行数を選べる版（Ⅵ：3行／5行／10行）と、子どもが自分で決めるカテゴリーの欄。
11. Ⅰ・Ⅱで、選択肢なし → ダミー1個 → ダミー3個と段階を踏む誤りなし学習版（Mueller et al. 2007；Markham et al. 2020）。
12. 各型に「生活の中でのつなげ方」の例を1つずつ載せる（しりとり・連想ゲームとして交互に行う、片付けでの分類 など）。
13. 絵を加えた版（就学前児・知的障害児向け）。ASDでは視覚的支援がEBP（Hume et al. 2021）。
